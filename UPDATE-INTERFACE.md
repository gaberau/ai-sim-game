# Chat, files, controls and calendar update

Extract this ZIP into your existing project folder, replacing matching source files. Launch using your working Launch-AI-Sim.bat. The ZIP leaves config/, saves/, build folders and launcher files alone.

- New games begin with Chat only. System access and tab visibility are independent; connecting chat, meeting people or completing work never reveals a view. Explicit player choices reveal views and those reveals persist. Older saves without a separate visibility ledger start with Chat only, preserving permissions, files, conversations and work. See UPDATE-TABS.md.
- The header includes weekday, date and time. Configure start_date in data/scenarios/hobbyist.toml for a new game. Dates persist; month lengths and leap years are correct. Next workday advances one calendar day, including weekends, skipping overnight hours.
- Files are organized as Work, Personal and Hidden. Left/Right selects a category. Q focuses the file list; E focuses content. Up/Down selects or scrolls. Enter opens file actions, including creation in the selected category. Changing category keeps identity, contents and access.
- Arrows navigate. Q focuses the left pane; E focuses the right. Stock WASD aliases and the old Q toggle are migrated in memory, so you do not need to replace keybindings.toml. Custom bindings remain supported; use focus_left and focus_right to configure pane keys. Q/E remain ordinary letters in text dialogs and editors.
- Chats show small authored choices under the selected incoming message. Left/Right browses incoming messages; Up/Down selects a choice; Enter responds. There is no large generic conversation-action menu. PageUp/PageDown reads a long message. Existing unfinished drafts have send/review/discard choices.

Opening and task branches live in data/conversations/opening.toml and first_workday.toml. Other incoming messages use the small profiles in responses.toml. All three definitions are snapshotted in the save; edits affect new games without rewriting ongoing choices. Legacy graph transcripts remain readable. Files can optionally specify category = 'work', 'personal', or 'hidden'; older entries are classified from their paths. Hidden is a category, not a permission change.

Eleven CTest suites cover calendar rollover/persistence, categories/access, authored responses, controls/migration, opening, workday, people, delegation, resource models, transport and saves. Four draw.io converter tests pass. Terminal layout and input checks run at 120x40 and 80x24. The Windows/WezTerm launcher is preserved; native Windows launching is not tested here.
